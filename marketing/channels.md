# Channels

How Happy shows up, per channel. Every post links to a page on happy.engineering or a release, and every claim follows the checklist in `positioning.md`. Log each post in `log.md`.

## Principles

- Show the product working: a screen recording beats a description. The homepage demo and the phone are our best assets.
- Lead with one audience per post (`positioning.md`), not the whole feature list.
- Name the competitor fairly when it is better at something. Our comparison pages already do; posts should too.
- Founders and builders post, not a brand voice. Kirill's account carries more than any company account.

## X

- **Who.** People building with Claude Code, Codex, and Grok, and the people they follow.
- **What.** Short demo clips (phone approving a change from a server, a mid-session model switch), release notes with a GIF, replies where someone asks for exactly what Happy does. Threads for the Vision essay's points, one per thread.
- **Cadence.** Something real each week; a release whenever one ships.
- **Research.** See the placeholder below.

## Reddit

- **Rule.** Every subreddit has its own self-promotion rules; read them before posting, post as a person who builds Happy, and say so. Answer questions in threads more than we start them.
- **What.** "I built X because Y" posts with a video, and honest answers in "how do you run Claude Code from your phone / on a server" threads.
- **Subreddits.** See the placeholder below for the list, with each one's rules.

## Hacker News

- **Show HN** once, for a real milestone: the agents-on-your-server story working end to end is the strongest candidate. Link the repository or a docs page, not the homepage. Be in the thread for the first hours.
- The Vision essay (`/vision/`) is a candidate for a plain submission.

## Directories and awesome lists

- Pull requests to awesome lists for Claude Code, Codex, and coding agents, each with the one-line description from `positioning.md` and a link to `/desktop-app/` or the repository.
- Product directories (AlternativeTo and similar): claim and correct; see `seo-backlog.md`.
- The four stale roundups in `seo-backlog.md` count here too: a corrected roundup is a better link than a new one.

## YouTube and demo video

- One 60-second video per audience: phone controlling a server agent; one session switching Claude, Codex, and Grok; pairing the phone. Upload to YouTube with the page link first in the description, and embed or link from the matching page.
- Reuse the same clips on X and Reddit.
