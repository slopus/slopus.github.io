# Plugin Privacy Policy

Last updated: October 1, 2026

## Scope

This policy covers the plugins Happy publishes for ChatGPT and Codex, starting with [Happy Memes](/plugins/memes/). The Happy app has its own [Privacy Policy](/privacy/).

## Summary

Happy Memes collects no personal data. Happy does not receive your prompts, files, chats, generated images, or account details when you use it.

## How Happy Memes Works

Happy Memes is a skills-only plugin: a set of written instructions that ChatGPT or Codex loads and follows. It has:

- No server, MCP server, or other connected service
- No account or sign-in
- No network requests of its own
- No analytics, telemetry, or tracking

## What We Collect

- **Personal data collected:** none.
- **Purposes of use:** none, because nothing is collected.
- **Recipients:** Happy does not send or sell data to anyone, because the plugin gives us none.
- **Retention:** nothing is retained, because nothing is collected.

## ChatGPT and Codex

Your requests, any web browsing, and image generation happen inside ChatGPT or Codex. OpenAI processes that data under its own policies, not this one:

- [OpenAI Privacy Policy](https://openai.com/policies/privacy-policy/)
- [OpenAI Terms of Use](https://openai.com/policies/terms-of-use/)

If you use a Happy plugin in another app that supports plugins, that app's privacy policy applies to what you do there.

## Installing from GitHub

If you install a plugin from its GitHub repository, GitHub handles the download under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). We can see only the aggregate traffic numbers GitHub shows repository owners, not who you are. If a plugin directory gives us aggregate statistics, such as install counts, those do not identify you either.

## Your Controls

You can stop using a Happy plugin at any time by disabling or removing it in ChatGPT or Codex. To manage your chat history, generated images, and other data held by OpenAI, use the controls in your OpenAI account settings.

## This Website

The pages on happy.engineering are static and hosted on GitHub Pages. Happy does not add cookies or analytics to the plugin pages. The pages load fonts from Google Fonts, and GitHub and Google may log requests, such as your IP address, under their own policies.

## Independence

Happy plugins are made by Happy. **They are not made, sponsored, or endorsed by OpenAI.** ChatGPT and Codex are trademarks of OpenAI.

## Changes to This Policy

If a Happy plugin ever starts collecting data, for example by adding a connected service, we will update this policy before that version ships and change the date above. Changes to this page are tracked in the website's public source repository.

## Contact

For questions about this privacy policy, please visit our [GitHub](https://github.com/slopus) or open an issue in the project's issue tracker.
