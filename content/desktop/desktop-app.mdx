# The Open Source Desktop App for Claude Code, Codex, Grok, and Gemini

Happy Desktop is a free, MIT-licensed app for orchestrating Claude Code, Codex, Grok, Gemini, and more on macOS, Windows, and Linux, reusing the subscriptions you already pay for. It is a Claude Code desktop app and a Codex desktop app in one window, signed in with your own logins.

Unlike the Code tab in Claude Desktop or Codex in the ChatGPT app, it runs every vendor's agents, and its code is open. The iOS and Android app is the phone half: the same sessions, end-to-end encrypted.

## Download the Claude Code and Codex desktop app

[Releases](/releases/) has the current Stable and Preview installers. On macOS or Linux you can also use Homebrew:

```sh
brew install --cask slopus/tap/happy
```

| Platform | Installer | Updates |
| --- | --- | --- |
| macOS, Apple Silicon or Intel | Signed and notarized `.dmg`, or Homebrew | The app updates itself |
| Windows, x64 | Signed `.exe` | The app updates itself |
| Linux, x64 or arm64 | `.AppImage`, or Homebrew | Through Homebrew |

Then sign in to Claude Code or Codex on the machine, if you haven't, and open Happy. It finds those sign-ins on its own. The [Quick Start](/quick-start/) goes from install to a first change. For your phone, get Happy from the [App Store](https://apps.apple.com/us/app/happy-codex-claude-code-app/id6748571505) or [Google Play](https://play.google.com/store/apps/details?id=com.ex3ndr.happy).

## How it compares

Anthropic and OpenAI each ship a desktop app for their own agent: the Code tab in [Claude Desktop](https://code.claude.com/docs/en/desktop), and Codex in the [ChatGPT desktop app](https://learn.chatgpt.com/docs/app). We checked their docs on October 9, 2026.

| | Happy Desktop | Claude Desktop, Code tab | ChatGPT desktop app, Codex |
| --- | --- | --- | --- |
| Made by | Happy Engineering | Anthropic | OpenAI |
| Models | Claude, GPT, and Grok; Claude and GPT through Amazon Bedrock; Gemini through Antigravity and any ACP agent (beta) | Claude | OpenAI's models |
| Switch models mid-session | Across Claude, GPT, and Grok; the transcript stays | Among Claude models | Among OpenAI models |
| Model access | Your Claude Code, Codex, or Grok CLI sign-in, or the agent's own for Antigravity and ACP agents; no Happy plan | Your Claude account | Your ChatGPT account |
| Platforms | macOS, Windows, Linux | macOS, Windows, Linux (beta) | macOS, Windows, Linux |
| Source code | Open, MIT | Closed | Closed |

If you use one vendor and want its newest features the day they ship, its own app is the better fit. Claude Desktop also does things Happy does not, such as cloud sessions, computer use, and an iOS Simulator pane. Happy is for running several vendors' agents in one place, on your own machine, with code you can read.

T3 Code is another open-source app for several vendors' agents. See [Happy vs T3 Code](/t3-code/).

## A Claude Code client that also runs Codex

Sign in to Claude Code and Happy runs Claude with Claude Code's prompts and tools on your Claude subscription. To run Claude Code's own agent loop instead (beta), with its settings, skills, and sub-agents, add a `[harnesses.claude_code]` table to `happy.toml`. Happy ships Claude Code, so there is nothing else to install.

Codex works the same way. By default Happy runs GPT models with Codex's prompts and tools; a `[harnesses.codex_cli]` table runs the Codex CLI itself (beta). See [Harnesses](/recepies/harnesses/).

## One harness, every model native

Claude gets Claude Code's prompts and tools, GPT models get Codex's, and Grok gets Grok Build's. Everything around the model is shared: one permission model, one sandbox, one set of tools. Change the model or reasoning effort as you go and the transcript stays. Subagents each pick their own model, so one task can plan on one provider and review on another. Happy can also run a vendor's whole agent instead (beta): Antigravity for Gemini, OpenCode, or any Agent Client Protocol (ACP) agent. See [Models & Subscriptions](/models/).

## Your subscriptions, no keys

Sign in to Claude Code, Codex, or the Grok CLI on the machine and Happy uses those credentials. There is no Happy plan for model access and no key to paste. Requests go to the vendor with your credentials; Happy never proxies them.

## Sessions that outlive the window

A headless runtime, Happy Agent, holds every session in a database on your machine. Quit the app and sessions keep running. Restart the runtime and they resume from disk. See [How It Works](/how-it-works/).

## Permissions and the sandbox

New sessions start in Auto. Reads and workspace edits run freely, everything else runs in the OS sandbox, and the few actions that cross the boundary are reviewed automatically by a separate agent. You are not prompted. See [Permissions & Sandbox](/permissions/).

## Your phone, encrypted

Pair the Happy app for iOS or Android once. Every session on the computer is on the phone, end-to-end encrypted. The relay sees ciphertext only. See [Claude Code on your phone](/mobile-app/).
