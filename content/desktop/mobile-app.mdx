# Claude Code and Codex on Your Phone

The Happy phone app is the mobile half of Happy, an open-source harness for orchestrating Claude, Codex, Grok, Gemini, and more on your computer. It is free on iPhone and Android. Pair your phone once with a QR code. Then send messages, answer permission requests, switch models, and read the changes from anywhere. The agents keep running on your machine, and the sync is end-to-end encrypted.

## Can I control Claude Code from my phone?

Yes. Pair the Happy app with Happy Desktop once by scanning a QR code. From then on you can start sessions, send messages, answer permission requests, switch models, and read the changes from your phone, while the agent keeps running on your computer.

## Does it work with Codex, Grok, and Gemini too?

Yes. Happy runs Claude, Codex, and Grok on the subscriptions you already pay for, and Gemini and any ACP agent on their own logins (beta). The phone shows all of their sessions.

## Do I need a terminal?

No. Happy Desktop runs the agents. If you already use the original Happy CLI (`happy` on npm), the same phone app works with it.

## Does my computer have to stay on?

The agents run on it, so yes. To keep them working while your laptop sleeps, run Happy Agent on a [remote server](/guides/remote-server/) and reach it from the same phone app.

## What does it cost?

The app is free and MIT licensed. Voice is the only thing we charge for; see [Voice](/voice/).

## Ways to reach your agent from a phone

| | Happy | Claude Code Remote Control | SSH and a terminal app |
| --- | --- | --- | --- |
| Agents | Claude, Codex, Grok, Gemini, and ACP agents, run by Happy Desktop | Claude Code | Anything you can run in a terminal |
| Phone app | Happy for iOS and Android | The Claude app for iOS and Android, or claude.ai/code in a browser | Any SSH client |
| Where the agent runs | Your computer | Your computer | Your computer |
| What sits in between | Happy's relay, which sees ciphertext only | Anthropic's servers, which store the transcript while connected | Nothing, if the phone can reach the machine |
| Made for a small screen | Yes | Yes | No, it is a terminal |
| Cost | Free, MIT licensed | Included with Claude Pro, Max, Team, and Enterprise | Free to paid, depending on the app |

Remote Control facts are from [Anthropic's Remote Control docs](https://code.claude.com/docs/en/remote-control), checked on October 9, 2026. For the details, see [Happy vs Claude Code Remote Control](/claude-code-remote-control/).

If you only use Claude Code and already have the Claude app, Remote Control is the shortest path: nothing else to install. If you want Codex too, or you want the content of your sessions unreadable to anyone in between, use Happy.

## Pairing

In Happy Desktop, open **Settings → Mobile Access**. Install Happy from the [App Store or Google Play](/#download), scan the device QR Desktop shows, and approve the computer on the phone. One scan.

Already using the original Happy CLI (`happy` on npm)? The same phone app works with it; see [its docs](/docs/).

## What you can do from the phone

Everything a session needs while you are away: messages with images, permission answers, stopping a turn, switching models, new sessions, and the files and Git changes. [Mobile Access](/mobile/#what-you-can-do-from-the-phone) has the full list.

## Privacy

Sessions are end-to-end encrypted, so Happy's relay sees ciphertext only; see [how the phone sync is encrypted](/mobile/#how-the-phone-sync-is-encrypted).
