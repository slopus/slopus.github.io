# Claude Code Mobile App for iPhone and Android

The Happy app is a free, open-source Claude Code mobile app, and it works the same way with Codex, Grok, and Gemini. It is the phone half of Happy, an open-source harness for orchestrating coding agents on your computer. Pair once with a QR code, and every session on your computer is on your phone, while the agents keep running there.

- **Platforms:** iPhone and Android, from the App Store and Google Play.
- **License:** MIT. The app's code is in [slopus/happy](https://github.com/slopus/happy).
- **How the phone reaches your computer:** both connect out to Happy's relay, so you open no ports. Sessions are end-to-end encrypted, and the relay passes on ciphertext it can't read.
- **Price:** free. Voice is the one paid feature, with 20 free minutes every 30 days.

## Can I control Claude Code from my phone?

Yes. Happy Desktop runs Claude Code on your computer, and the phone app shows the same sessions. From your phone you can start a session, send a message, answer a permission request, stop a turn, or switch models. Nothing runs on the phone itself.

## Set up Claude Code on your phone

1. In Happy Desktop, open **Settings → Mobile Access**.
2. Install Happy from the [App Store or Google Play](/#download). Desktop shows a QR code for the listing.
3. Scan the device QR Desktop shows next, and approve the computer on the phone.

That is the only scan. A computer you have linked before is reused.

## What you can do with Claude Code from your phone

Everything a session needs while you are away: messages with images, permission answers, stopping a turn, switching models and effort, new sessions in a directory you pick, and the session's files and Git changes. [Mobile Access](/mobile/#what-you-can-do-from-the-phone) has the full list.

## Is there an official Claude Code mobile app?

Anthropic's Claude app for iOS and Android can continue a Claude Code session through [Remote Control](https://code.claude.com/docs/en/remote-control). Happy is a separate app, made by us and MIT licensed. It also runs Codex, Grok, and Gemini, and the server in between can't read your sessions.

If you only use Claude Code and already have the Claude app, Remote Control is the shortest path: nothing else to install. If you want Codex too, or you want your sessions unreadable to anyone in between, use Happy.

## Ways to use Claude Code on your phone

| | Happy | Claude Code Remote Control | SSH and a terminal app |
| --- | --- | --- | --- |
| Agents | Claude, Codex, Grok, Gemini, and ACP agents, run by Happy Desktop | Claude Code | Anything you can run in a terminal |
| Phone app | Happy for iOS and Android | The Claude app for iOS and Android, or claude.ai/code in a browser | Any SSH client |
| Where the agent runs | Your computer | Your computer | Your computer |
| What sits in between | Happy's relay, which sees ciphertext only | Anthropic's servers, which store the transcript while connected | Nothing, if the phone can reach the machine |
| Made for a small screen | Yes | Yes | No, it is a terminal |
| Cost | Free, MIT licensed | Included with Claude Pro, Max, Team, and Enterprise | Free to paid, depending on the app |

Remote Control facts are from [Anthropic's Remote Control docs](https://code.claude.com/docs/en/remote-control), checked on October 9, 2026. For the details, see [Happy vs Claude Code Remote Control](/claude-code-remote-control/).

## Does the Claude Code phone app work with Codex, Grok, and Gemini?

Yes. Happy runs Claude, Codex, and Grok on the subscriptions you already pay for, and Gemini and any ACP agent on their own logins (beta). The phone shows all of their sessions in one list.

## Do I need a terminal?

No. Happy Desktop runs the agents. If you already use the original Happy CLI (`happy` on npm), the same phone app works with it; see [its docs](/docs/).

## Does my computer have to stay on?

The agents run on it, so yes. To keep them working while your laptop sleeps, run Happy Agent on a [remote server](/guides/remote-server/) and reach it from the same phone app.

## Can Happy read my sessions?

No. Sessions are end-to-end encrypted, so Happy's relay sees that machines and sessions exist, not what is in them. See [how the phone sync is encrypted](/mobile/#how-the-phone-sync-is-encrypted).

## What does it cost?

The app is free and MIT licensed. Voice is the only thing we charge for: 20 free minutes every 30 days, then a subscription. See [Voice](/voice/).
