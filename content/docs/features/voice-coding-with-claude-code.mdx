# Voice Coding with Claude Code

Voice coding with Claude Code in Happy happens on your phone. Open a session in the Happy app, tap the mic, and talk. A voice agent, also called Happy, turns what you say into a message for Claude Code in that session, sends it once you have finished, and tells you when Claude Code is done.

It runs on ElevenLabs. **[Voice with ElevenLabs](/voice/)** has the details: how a conversation starts, what ElevenLabs hears, and the limits.

## How voice coding with Claude Code works

```
You talking -> Voice agent (ElevenLabs) -> Claude Code session -> Your code
```

The voice agent doesn't write code or make decisions. It assumes you are thinking out loud about what you will ask Claude Code, and waits until you have said the whole request before sending it. Claude Code does the work, the same as when you type.

- **It answers to "Happy, …"** or a clear follow-up. When you are talking to someone else in the room, it stays quiet. Its replies are one sentence.
- **It knows your sessions.** It starts with a list of your active sessions and up to 50 recent messages from the one you have open. Switch sessions and it follows you. It can also send a message to a session in the background.
- **It tells you when Claude Code is done**, even if you said nothing.
- **It reads permission requests out loud.** It allows or denies one only when you say so, unless you tell it to accept the ones that follow.
- **It speaks your language.** Pick it in **Settings → Voice**.

What voice sends is an ordinary message in the session. When you get back to your computer, the session has your requests and everything Claude Code did with them.

## Free minutes and the subscription

Voice is free for 20 minutes every 30 days. A subscription in the app raises that to 5 hours. The subscription pays for voice and for our open source work. **Settings → Voice** shows how many minutes you have used.

## Use your own ElevenLabs agent

**Settings → Voice → Bring Your Own Agent** takes the ID of an agent in your ElevenLabs account. The app then connects to ElevenLabs with that agent directly: no minutes counted by us, no paywall, and ElevenLabs bills you.

You write that agent's prompt in ElevenLabs, so you can change how voice behaves without rebuilding the app. Once the ID is set, the app shows what the agent needs: a `sendMessageToSession` tool, a `processPermissionRequest` tool, and the `{{initialConversationContext}}` variable, which carries the session history.

## What ElevenLabs hears

Your microphone audio, your list of active sessions, the recent messages of the session you have open, new messages as they arrive, and permission requests with their arguments. Messages between your devices are end-to-end encrypted; voice sends this part from your phone to ElevenLabs. If a session holds something you wouldn't hand to a third party, don't open voice on it. [The full list](/voice/#what-elevenlabs-hears).

## Why talk to Claude Code at all

After a day at the desk, you often still have ideas but no energy for another desk session. Voice is worse than typing, and it doesn't need to be better. It turns an evening on the couch, a walk, or a drive into time where Claude Code can try the refactor you keep putting off: stub out the new structure, write up the plan, file the issues.

When something looks good, go to your computer and carry on in the same session.

## Voice on Happy Desktop

Happy Desktop has experimental voice calls of its own, on OpenAI's GPT-Live instead of ElevenLabs, under **Settings → Experimental → Voice calls**. [Voice with ElevenLabs](/voice/#gpt-live-on-happy-desktop) covers them.
