# Quick Start Guide

The original Happy CLI (Happy Coder) runs Claude Code on your computer and lets you steer it from your phone. Install the app, install the CLI, and pair them with a QR code.

## Installation

<Steps>

### Download Mobile App

- **iPhone/iPad**: [App Store](https://apps.apple.com/us/app/happy-codex-claude-code-app/id6748571505)
- **Android**: [Google Play](https://play.google.com/store/apps/details?id=com.ex3ndr.happy)
- **Web App**: [app.happy.engineering](https://app.happy.engineering)

### Install on Your Computer

```bash
npm install -g happy
```

Happy requires Node.js 20 or later.

### Scan the QR code with your mobile app

```bash
happy auth login   # choose "Mobile App" to show a QR code
```
