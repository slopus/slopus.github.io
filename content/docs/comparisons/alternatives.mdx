# Alternatives for Claude Code and Codex on Mobile and Desktop

There are six common ways to run Claude Code or Codex from a desktop app or your phone: Happy, Anthropic's Remote Control, Codex in the ChatGPT app, T3 Code, Conductor, and SSH with tmux. They differ in which agents and models they run, whether they have a harness of their own, whether a team can share them, which devices they reach, and what sits in between.

## Side by side

Facts about the other tools come from their own docs and sites, checked on November 4, 2026. They ship often, so follow the links for the current state.

Direct, for Happy: Happy Desktop reaches a [Happy Agent server](/guides/remote-server/) over [Tailcat](/tailcat/), a WireGuard tunnel that goes machine to machine when the network allows and through a relay that only forwards ciphertext when it doesn't. A phone can pair directly over Tailcat too, in Happy Desktop 0.0.102 and later, but that is experimental: Relay stays selected by default, and the phone apps in the stores don't support it yet.

Whichever you pick, the agent runs on a machine of yours, so that machine has to be on. Put it on a [remote server](/guides/remote-server/) and it keeps working while your laptop sleeps.

## Happy

Happy is an open-source harness for orchestrating coding agents: Claude, Codex, Grok, Gemini, and more in one desktop app, reusing the subscriptions you already pay for.

- **Several models in one app.** Claude, GPT, and Grok, reusing the subscriptions you already pay for. A conversation can switch between them and keep its transcript. See [Models](/models/).
- **Its own harness.** Happy Agent runs the agent loop itself, with one OS sandbox and Auto review for every model. It can also run Claude Code's and Codex's own loops (beta), and other agents over ACP. See [Harnesses](/recepies/harnesses/).
- **Teams.** One Happy Agent on a server, where each member signs in as themselves, through WorkOS or your own identity provider, and works in the same projects and sessions. See [Multiplayer & Teams](/multiplayer/).
- **Desktop and phone.** [Happy Desktop](/desktop-app/) for macOS, Windows, and Linux, and the [phone app](/mobile-app/) for iPhone and Android, which reaches every session.
- **Open source.** MIT licensed, the apps and the agent runtime.
- **End-to-end encrypted.** Happy's relay only sees ciphertext.

Sessions belong to Happy Agent, a runtime under the app, so quitting the window doesn't stop them.

What it doesn't do: there is no web client, and team setup takes several steps today.

## Claude Code Remote Control

[Remote Control](https://code.claude.com/docs/en/remote-control) connects the Claude app or claude.ai/code to a Claude Code session on your computer. Run `claude remote-control`, or `/remote-control` in a session, and scan the QR code. If you already pay for Claude and only use Claude Code, this is the least setup of anything here.

It runs Claude Code only. It needs a claude.ai login, so it doesn't work with API keys, Amazon Bedrock, Google Cloud, Microsoft Foundry, or a custom `ANTHROPIC_BASE_URL`. On Team and Enterprise an owner has to turn it on first.

Anthropic's [cloud sessions](https://code.claude.com/docs/en/claude-code-on-the-web) run on its own infrastructure from a GitHub repository, and you follow them from the same app. On Team and Enterprise you can share a cloud session's link with your organization; teammates see it as it was when they open it.

For the details, see [Happy vs Claude Code Remote Control](/claude-code-remote-control/).

## Codex in the ChatGPT app

The ChatGPT desktop app on macOS or Windows can [let your phone control it](https://learn.chatgpt.com/docs/remote-connections). Pair it in **Settings > Connections > Control this Mac or PC** with a QR code, then open **Codex** in ChatGPT on iOS or Android. From the phone you can start chats, steer them, approve commands, and read diffs.

Setup has to start in the desktop app; the Codex CLI and IDE extension can't do it. A workspace admin may need to enable it. To show a thread to a teammate, the macOS app [shares a read-only snapshot](https://learn.chatgpt.com/docs/use-chatgpt); later messages don't update it.

## T3 Code

[T3 Code](https://github.com/pingdotgg/t3code) is a free, MIT-licensed app that runs Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity, and fx on your subscriptions, plus other ACP agents. It has a desktop app for macOS, Windows, and Linux, phone apps, and a web client at app.t3.codes. It also has tools for app work, such as a live iOS Simulator or Android Emulator next to the thread.

Each vendor's own agent does the work, under that vendor's sandbox. New threads start in Full access unless you change the default. A guest link (beta) lets one person follow a thread and suggest messages for you to send; there is no team server where each person signs in as themselves.

For the details, see [Happy vs T3 Code](/t3-code/).

## Conductor

[Conductor](https://www.conductor.build/docs) runs Claude Code, Codex, Cursor, and OpenCode in parallel on your Mac, each task in its own workspace and branch, with a diff viewer, and opens the pull request when the work is ready. Local use is free with your own subscriptions or keys.

Its [Remote Control](https://www.conductor.build/docs/reference/remote-control) for the iPhone app is experimental and works with local workspaces only. Traffic goes through Conductor's relay, end-to-end encrypted. On the [Pro plan](https://www.conductor.build/pricing), $50 a month, cloud workspaces run in Vercel sandboxes and are [shared with your organization](https://www.conductor.build/docs/cloud/collaboration): teammates open the same chats and see them update live. Conductor stores cloud workspaces' messages on its servers. It is Mac only, with no Android app, and its source is not public.

## SSH, tmux, and Termius

Run Claude Code or Codex inside tmux on your computer, then attach from an SSH app such as [Termius](https://termius.com) on your phone. Most people put both on a private network such as Tailscale so the machine needs no open port.

Nothing sits in between, and it works with any agent that runs in a terminal. You get a terminal on a phone screen, though: small text, no touch-sized controls, and no alert when the agent stops to ask you something unless you set one up yourself.

## What happened to Omnara

Omnara used to be a phone app for Claude Code. As of November 4, 2026, [its site](https://www.omnara.com/) calls it "The open-source alternative to Claude Managed Agents": an API and platform for running agents, not a remote for your Claude Code session.
