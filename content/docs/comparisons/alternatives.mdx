# Alternatives for Claude Code and Codex on Mobile and Desktop

There are six common ways to run Claude Code or Codex from your phone or a desktop app: Anthropic's Remote Control, Codex in the ChatGPT app, T3 Code, Conductor, Happy, and SSH with tmux. In all six the agent runs on a computer you own, and the app is a window into it. They differ in which agents they run, which devices they reach, what the server in between can read, and what they cost.

## Side by side

Facts about the other tools come from their own docs and sites, checked on November 4, 2026. They ship often, so follow the links for the current state.

## Claude Code Remote Control

[Remote Control](https://code.claude.com/docs/en/remote-control) connects the Claude app or claude.ai/code to a Claude Code session on your computer. Run `claude remote-control`, or `/remote-control` in a session, and scan the QR code. If you already pay for Claude and only use Claude Code, this is the least setup of anything here.

It runs Claude Code only. It needs a claude.ai login, so it doesn't work with API keys, Amazon Bedrock, Google Cloud, Microsoft Foundry, or a custom `ANTHROPIC_BASE_URL`. On Team and Enterprise an owner has to turn it on first.

If your laptop will be closed, Anthropic's [cloud sessions](https://code.claude.com/docs/en/mobile) run on its own infrastructure from a GitHub repository, and you follow them from the same app.

For the details, see [Happy vs Claude Code Remote Control](/claude-code-remote-control/).

## Codex in the ChatGPT app

The ChatGPT desktop app on macOS or Windows can [let your phone control it](https://learn.chatgpt.com/docs/remote-connections). Pair it in **Settings > Connections > Control this Mac or PC** with a QR code, then open **Codex** in ChatGPT on iOS or Android. From the phone you can start chats, steer them, approve commands, and read diffs.

Setup has to start in the desktop app; the Codex CLI and IDE extension can't do it. A workspace admin may need to enable it. If the host sleeps or closes the app, the phone loses it until it's back.

## T3 Code

[T3 Code](https://github.com/pingdotgg/t3code) is a free, MIT-licensed app that runs Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity, and fx on your subscriptions, plus other ACP agents. It has a desktop app for macOS, Windows, and Linux, phone apps, and a web client at app.t3.codes. It also has tools for app work, such as a live iOS Simulator or Android Emulator next to the thread.

Each vendor's own agent does the work, under that vendor's sandbox. New threads start in Full access unless you change the default. There is no team server where each person signs in as themselves.

For the details, see [Happy vs T3 Code](/t3-code/).

## Conductor

[Conductor](https://www.conductor.build/docs) runs Claude Code, Codex, Cursor, and OpenCode in parallel on your Mac, each task in its own workspace and branch, with a diff viewer, and opens the pull request when the work is ready. Local use is free with your own subscriptions or keys.

Its [Remote Control](https://www.conductor.build/docs/reference/remote-control) for the iPhone app is experimental and works with local workspaces only. Traffic goes through Conductor's relay, end-to-end encrypted. The [pricing page](https://www.conductor.build/pricing) lists the mobile app, cloud workspaces, and multiplayer in Pro at $50 a month. It is Mac only, with no Android app, and its source is not public.

## Happy

Happy is an open-source harness for orchestrating coding agents: Claude, Codex, Grok, Gemini, and more in one desktop app, reusing the subscriptions you already pay for. [Happy Desktop](/desktop-app/) runs on macOS, Windows, and Linux. The [phone app](/mobile-app/) for iPhone and Android reaches every session, and Happy's relay only sees ciphertext.

Sessions belong to Happy Agent, a runtime under the app, so quitting the window doesn't stop them. A conversation can switch between Claude, GPT, and Grok and keep its transcript. Teams can run one Happy Agent on a server where each member signs in as themselves.

What it doesn't do: there is no web client. Your computer has to stay on, unless you run Happy Agent on a remote server. Vendor features land in the vendor's own app first. Team setup takes several steps today.

## SSH, tmux, and Termius

Run Claude Code or Codex inside tmux on your computer, then attach from an SSH app such as [Termius](https://termius.com) on your phone. Most people put both on a private network such as Tailscale so the machine needs no open port.

Nothing sits in between, and it works with any agent that runs in a terminal. You get a terminal on a phone screen, though: small text, no touch-sized controls, and no alert when the agent stops to ask you something unless you set one up yourself.

## What happened to Omnara

Omnara used to be a phone app for Claude Code. As of November 4, 2026, [its site](https://www.omnara.com/) calls it "The open-source alternative to Claude Managed Agents": an API and platform for running agents, not a remote for your Claude Code session.

## Which one

| You want | Use |
| --- | --- |
| Claude Code on your phone with nothing new to install | Claude Code Remote Control |
| Codex on your phone, and you already use the ChatGPT app | Codex in the ChatGPT app |
| Work that keeps going while your laptop is closed, with no server of your own | Claude Code cloud sessions |
| A web client for the machine your agents run on | T3 Code |
| Parallel workspaces and pull requests on a Mac | Conductor |
| Claude, Codex, and Grok in one desktop app, on any OS, plus an encrypted phone app | Happy |
| One agent server for a team, each person signed in | Happy |
| No company in between at all | SSH and tmux |
