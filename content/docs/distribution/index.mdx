### Full Description (500+ characters)
```
Happy is an open-source harness for orchestrating coding agents: Claude, Codex, and Grok in one desktop app, reusing the subscriptions you already pay for. Happy Desktop runs on macOS, Windows, and Linux; the Happy phone app for iOS and Android follows the same sessions, and Happy Agent also runs on a server, alone or for a team.

Features:
- Claude, Codex, and Grok in one app, each with its vendor's own prompts and tools
- Sign in with the subscriptions you already pay for; no Happy plan
- Subagents on any model, and sessions that survive restarts
- End-to-end encrypted phone app for iPhone and Android
- Run one Happy Agent for your whole team: shared projects and sessions, each member with their own sign-in
- Open source (MIT licensed)
```

### The original Happy CLI
```
The original Happy CLI (Happy Coder) is a phone remote for Claude Code and Codex in your terminal: run `happy` on your computer and steer the session from your phone. Open source, free, now in maintenance mode.
```
