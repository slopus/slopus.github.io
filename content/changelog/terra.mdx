We've removed GPT-5.6 models from the picker. **If a chat uses GPT-5.6, switch it to another model before continuing.**

### Stops survive restarts

Stopped conversations stay stopped after Happy Agent restarts, and your next message no longer waits behind an unwanted reply. Work interrupted by a crash still resumes.

### Bots and tasks can set up MCP

Bots and tasks can configure MCP servers in their own folders, alongside the servers available across your installation and projects.

### More stable inline pages

Updated artifact guidance helps agents build inline pages that keep a steady height as their content changes.
